# Flake catalogue

Every class of visual flake snapcheck has observed in a real Storybook build,
how it shows up, and what — if anything — removes it. Cumulative: a class stays
here after it is fixed, and classes that **cannot** be fixed are listed with the
same weight as the ones that can.

"Flake" means one build, one environment, different pixels between runs. The
evidence is the determinism rig (`pnpm rig:determinism`), which requires runs
to be pixel-identical with zero tolerance.
